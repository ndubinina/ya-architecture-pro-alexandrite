## Мотивация
- мониторинг позволяет отсеживать работоспособность системы и достаточность ресурсов и своевременно реагировать на проблемы, чтобы минимизировать недовольство клиентов и финансовые потери
- мониторинг позволяет быстро сделать гипотезы в случае наступления проблем
- мониторинг позволяет отслежить эффект релиза на работоспособность системы

## Выбор подхода к мониторингу
на Shop API, CRM API, MES API - RED+USE (для понимания ресурсов серверов и понимания, как их работоспособность выглядит со стороны клиентских систем)
на серверах БД, Rabbit MQ - USE (нужно отслеживать состояние ресурсов серверов)

## Набор метрик

| Метрика                                             | Где                                                                 | Назначение                                                                      | Ярлыки                                                                                                                                     |
|-----------------------------------------------------|---------------------------------------------------------------------|---------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| RPS - число запросов http                           | MES API, CRM API, internet shop API                                 | Наблюдение за общей нагрузкой на сервис, изменением трафика, появлением ошибок  | http status(200, 400) - для отслеживания числа успешных и ошибочных запросов, http type - тип запроса (GET/POST) и endpoint для фильтрации |
| Error RPS - число http-запросов со статусом 500     | MES API, CRM API, internet shop API                                 | Отслеживание появления ошибок                                                   | http status(500, 503) - для отслеживания числа ошибочных запросов, http type - тип запроса (GET/POST) и endpoint для фильтрации            |
| RPS per user - число http запросов клиента          | MES API, CRM API, internet shop API                                 | Поиск аномального поведения, анализ пользовательской активности                 | http status(200, 500) - для отслеживания числа успешных и ошибочных запросов, http type - тип запроса (GET/POST) и endpoint для фильтрации |
| Response time (latency)                             | MES API, CRM API, internet shop API                                 | Наблюдение за здоровьем сервиса, его usability с точки зрения времени ответа    | http status(200, 500) - для отслеживания числа успешных и ошибочных запросов, http type - тип запроса (GET/POST) и endpoint для фильтрации |
| CPU %                                               | MES API, CRM API, internet shop API, shop db, MES db, Rabbit MQ     | Контроль за достаточностью ресурсов серверов, необходимости масштабирования     | instance - идентификатор инстанса                                                                                                          |
| Memory Utilisation                                  | MES API, CRM API, internet shop API, shop db, MES db, Rabbit MQ     | Обнаружение проблем с нехваткой ресурсов, позволяет выявить утечки памяти       | instance - идентификатор инстанса                                                                                                          |
| Disk size                                           | MES API, CRM API, internet shop API, shop db, MES db, Rabbit MQ, s3 | Своевременное обнаружение переполнения дисков                                   | instance - идентификатор инстанса                                                                                                          |
| Время нахождения заказа в определенном статусе      | MES API, CRM API, internet shop API                                 | Позволяет находить узкие места в процессе                                       | status - статус, type - B2C или B2B                                                                                                        |
| Число сообщений в RabbitMQ в статусе ready          | Rabbit MQ                                                           | Позволяет понять, нет ли задержек в обработке, нет ли сообщений в DLQ           | queue - очередь (включая DLQ)                                                                                                              |
| Число сообщений в RabbitMQ в статусе unacknowledged | Rabbit MQ                                                           | Позволяет понять - нет ли проблем на consumer, нет ли долгих/зависших обработок | queue - очередь                                                                                                                            |
| Connection size                                     | shop db, MES db                                                     | Позволяет отследить долгие транзакции, неверную настройку connection pool       |                                                                                                                                            |
| Replication lag                                     | shop db, MES db                                                     | Обнаружение задержек в репликации                                               |                                                                                                                                            |
| Number of simultanious sessions                     | MES API, CRM API, internet shop API                                 | Оценка количества активных пользователей и его влияение на нагрузку системы     |                                                                                                                                            |

## План действий
- добавить и настроить OpenTelemetry в C# (MES API), включить сбор метрик
- добавить и настроить micrometer-registry-prometheus в Spring Boot(Shop API, CRM API), включить сбор метрик
- добавить и настроить pg_stat_statements и postgres_exporter в базы данных postgres (shop db, MES db), включить сбор метрик
- добавить rabbitmq_prometheus в Rabbit MQ, включить сбор метрик
- развернуть инстансы Grafana и Prometheus на тестовой и продовой средах
- настроить дашборды Grafana
- настроить уведомления в случае критичного роста ошибок или нехватки ресурсов
